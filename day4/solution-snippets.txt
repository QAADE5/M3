Day 4 - Run the Pipeline Locally - stretch hints

Some snippets for the stretch tasks. These are starting points, not
drop-in code -- you'll still need to work out where each piece goes and
fix at least one thing yourself.

--- Write failing rows to rejected.csv ---

The check pattern used elsewhere only tells you a check failed, not
which rows caused it. You need to filter the dataframe separately:

    bad_rows = df[pd.to_numeric(df['quantity'], errors='coerce') <= 0]

From there it's just pandas -- write bad_rows out to rejected.csv
however you like.
